## 🚀 What is qchat?

qchat is a lightweight app that lets you create a private group chat in seconds. You don’t need to sign up or create accounts. Just one command, one QR code, and your group is ready. It is designed for quick, temporary conversations without the hassle of registration or invites.

Use qchat when you want to share ideas, plan events, or chat in a team without leaving a trace afterward. The chat ends when everyone leaves. Simple and private.

## 💻 System Requirements

- Windows 10 or later (64-bit recommended)

- 100 MB free disk space
- Internet connection for sharing the QR code and joining chat rooms

qchat runs on most modern Windows machines without installing additional software. It works offline between users on the same network once the chat starts, but initial connection needs internet.

## 🔑 How to Use qchat

### Create a new chat

- Open qchat.

- The app will show a command prompt area and a QR code.

- The QR code is unique to your chat session.

- Share the QR code with your friends or colleagues. They scan it with their device cameras to join.

### Join a chat

- If you get a QR code from someone else, open qchat on your Windows device.

- Find the “Join Chat” option.

- Use your device camera or a QR code scanner app to scan the code.

- You will automatically enter the group chat.

### Chat features

- Send text messages instantly.

- Share emojis and simple attachments like images.

- The chat closes when everyone leaves.

- No account creation or signup is required.

## ❓ Troubleshooting

**I can’t scan the QR code**

- Make sure your camera has permission to operate.

- Try increasing the brightness or zooming in on the QR code.

- Use a separate QR scanning app if qchat’s scanner doesn’t work.

**qchat won’t open or crashes**

- Check that your Windows system is up to date.

- Run the program as an administrator: right-click the file and select “Run as administrator”.

- Disable any antivirus software temporarily to see if it blocks qchat.

**My friends can’t join the chat**

- Confirm everyone is scanning the correct QR code.

- Make sure everyone is on the same network or has internet access for the initial connection.

- Restart qchat and try creating a new chat.

## 🔐 Privacy and Security

qchat does not keep chat records after the chat ends. It does not require usernames or passwords. The QR code acts as the only key to enter the chat. When the chat closes, all data is deleted to protect your privacy.
